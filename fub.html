How to install it in FUB

  1. Click Copy FUB Signature.
  2. In Follow Up Boss, open My Settings → Signature.
  3. Paste directly into the signature editor. Do not use Import signature.
  4. If you chose Clean / No Photo, save it and send yourself a test email.
  5. If you chose Photo-Ready, click the ADD HEADSHOT box on the right, remove that text, then use FUB’s picture icon to insert your image. If FUB will not place the photo cleanly, delete the right box and use the clean version instead.
  6. Click Save signature, then send a test email from FUB.
